# Версии, резервная копия и экспорт

## Версия

Храни персональные версии в `resumes/<локальный-id>/<время>_<язык>/`;
исходный снимок и журнал согласований — в `private/`.
Используй переносимые имена без разделителей пути, двоеточий и личных контактов.
Не перезаписывай исходный файл. Версия содержит выбранный язык,
ID исходного резюме, время с часовым поясом, готовый текст и согласованные
существенные изменения. Не записывай пароли, cookies и токены.

Стабильный ID веб-резюме не меняется из-за его переименования или правки.
Он же используется при исключении повторных откликов. Для локального файла
без ID создай один локальный идентификатор и сохраняй его между версиями;
не вычисляй идентичность только по названию или изменяемому содержимому.

## Выбор экспорта

Уточни нужные форматы, если они не заданы: PDF, DOCX и/или Markdown.
Предпочти штатное скачивание сайта, если оно сохраняет выбранную версию
и удовлетворяет требуемому формату. Проверь, какой документ реально скачан.
Для собственного оформления используй доступные инструменты документов/PDF
и их инструкции. Скиллы `documents` и `pdf` полезны, если установлены,
но не являются обязательной зависимостью этого набора.

Если специальных инструментов нет:

- Markdown сохраняй непосредственно в UTF-8;
- DOCX создай доступной библиотекой, например `python-docx`, либо совместимым
  редактором; переименование `.md`/`.html` в `.docx` недопустимо;
- PDF получи штатным экспортом или печатью доступного браузера/редактора,
  либо доступной PDF-библиотекой, например ReportLab, с Unicode-шрифтом;
- отсутствующую зависимость установи только в рамках разрешённой локальной
  среды; если это недоступно, отдай готовый текст и назови недоступный формат.
  Не объявляй текстовый черновик готовым PDF/DOCX.

Сохранение финального локального экспорта по запросу пользователя не требует
ещё одного согласования, если содержание уже согласовано.

## Проверка качества

Проверь все выбранные языки отдельно, не создавай незаказанные переводы.
Обязательно проверь казахские символы `Ә ә Ғ ғ Қ қ Ң ң Ө ө Ұ ұ Ү ү Һ һ І і`.
В PDF шрифт должен поддерживать используемые символы и быть встроен.
Извлеки текст из PDF/DOCX и сравни имена, даты, контакты, заголовки и порядок.
Для PDF просмотри отрендеренные страницы; для DOCX, где есть средства,
сделай визуальную проверку через PDF/изображения.
Проверь отсутствие обрезанного текста, пустых случайных страниц и одиноких
заголовков. Если визуальная проверка недоступна, назови её непроведённой.

Финальные файлы не должны содержать комментарии редактора, неподтверждённые
метрики, служебные допущения или секреты. Ссылка на PDF должна вести к
реальному проверенному PDF, а не к обещанию его создать.
