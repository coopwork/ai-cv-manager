# Анализ и улучшение резюме

Прочитай [контекст кандидата](references/candidate-context.md).
При работе с сайтом также прочитай [подключение браузера](references/browser-session.md)
и [площадку](references/platforms.md). Если достаточно прикреплённого файла,
не запрашивай доступ к аккаунту.

## Разбор

Определи выбранные языки, резюме и целевую роль. Если цель не названа,
используй название резюме как предварительное направление и уточни его.
Извлеки сведения из всего документа/веб-резюме, включая даты, обязанности,
результаты, навыки, образование и ссылки. Недоступные разделы отметь явно.
Если файл не читается, попроси читаемую копию; не оценивай отсутствующее содержимое.

Прочитай [практики ATS](references/ats.md) и [рубрику](references/review-rubric.md).
Для конкретной вакансии прочитай полную карточку, затем составь соответствие
требований и свидетельств из резюме. Для общего анализа не собирай вакансии
без необходимости; при потребности в рыночном контексте согласуй направление
и используй небольшую релевантную выборку.

Оцени ясность целевой роли, релевантность, вклад и результаты, структуру,
навыки и согласованность. Опирайся на цитируемые фрагменты резюме.
Не выводи вероятность найма из собственной балльной оценки.

## Результат

Дай на выбранном языке:

1. Оценку по рубрике с объяснением, что это редакторская оценка, а не рейтинг сайта.
2. Главные препятствия для выбранной роли и приоритет изменений.
3. Конкретные варианты «было → стало» для заголовка, краткого профиля
   и наиболее важных описаний опыта.
4. Для вакансии — таблицу «требование → подтверждение → пробел/действие».
5. Короткий список сведений, которые пользователь должен уточнить:
   новые числа, должности, даты или другие существенные изменения.

Разделяй готовые формулировки и неподтверждённые предложения. Предлагай
сильные варианты, включая оценки масштаба, с явными допущениями.
Не меняй сайт и не отправляй резюме в рамках анализа. По запросу сохрани
отчёт в `reports/`; для редактирования выбери `resume-edit`, если он установлен,
или прочитай соответствующий локальный скилл. Не обрывай уже разрешённую задачу
только ради предложения «могу продолжить».
